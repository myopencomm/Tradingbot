  cd Tradingbot
  python3 -m venv venv
  venv/bin/pip install -r requirements.txt
  cp .env.example .env
  cp positions.example.json positions.json

Installation — Etape 4 : Lancer
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ./bot.sh start

Le bot tourne en arriere-plan — tu peux
fermer le terminal. Envoie /start ici
pour verifier.

Recommande — demarrage auto au boot du Mac/PC
+ relance automatique apres un crash :
  ./bot.sh autostart

Autres commandes :
  ./bot.sh status   → tourne ou pas ?
  ./bot.sh logs     → logs en direct
  ./bot.sh stop     → arreter

Installation — Etape 5 : mesurer la perf
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Le cash de depart que tu viens de saisir
est la MISE INITIALE de ton fonds.

/nav → la croissance de ton investissement
en %, comme un fonds : la part vaut 100 au
depart, "elle vaut 117" = +17%.

UNE SEULE CHOSE A RETENIR :
chaque fois que tu vires ou retires de
l'argent, declare-le :
  /nav depot 1000
  /nav retrait 500

Sinon ton virement serait compte comme une
performance du bot. Il ne peut pas deviner :
sur le solde, un virement et un gros gain
se ressemblent.

Le reste est automatique — releve chaque
soir a 22h15, graphique dans /dashboard.

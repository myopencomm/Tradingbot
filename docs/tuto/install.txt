Installation — Etape 2 : Telecharger
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Dans ton terminal :
  git clone https://github.com/myopencomm/Tradingbot.git
  cd Tradingbot
  python3 -m venv venv
  venv/bin/pip install -r requirements.txt
  cp .env.example .env
  cp positions.example.json positions.json

Python 3.10 minimum requis.
Sur Mac si python3 --version affiche 3.9 :
  brew install python

Installation — Etape 4 : Lancer
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ./bot.sh start

Le bot tourne en arriere-plan — tu peux
fermer le terminal. Envoie /start ici
pour verifier.

Recommande — demarrage auto au boot du Mac/PC
+ relance automatique apres un crash :
  ./bot.sh autostart

Autres commandes :
  ./bot.sh status   → tourne ou pas ?
  ./bot.sh logs     → logs en direct
  ./bot.sh stop     → arreter
